# Exploratory-Data-Analysis-EDA

## Objective
Perform Exploratory Data Analysis on the Titanic dataset to identify patterns, trends, and anomalies.

## Tools Used
- Python
- Pandas, NumPy
- Matplotlib, Seaborn
- Jupyter Notebook

##  Steps Performed in Titanic EDA

1. Loaded Titanic Dataset 
2. Explored Dataset Structure 
3. Checked Missing Values
4. Performed Descriptive Statistics 
5. Created Visualizations
   - Histograms 
   - Count plots 
   - Box plots
   - Correlation heatmap
   - Pair plots
6. Recorded Observations  
   - Noted that females, first-class passengers, and children had higher survival rates.  
   - Highlighted correlation between class and fare.  
   - Pointed out missing data handling importance.
